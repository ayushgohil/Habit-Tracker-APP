# Security policy

## Supported versions

Security fixes go into the latest release. Please update to the newest version before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

1. Preferred: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainers can see the report.
2. Or email ayush.gohil12@gmail.com with the details.

Please include what you found, the steps to reproduce it, the Ember version and your Android version. You will get a reply within a few days. Once a fix is released we are glad to credit you, if you wish.

## What counts

Ember keeps everything on your device, so the most relevant problems are things like reading habit data without permission, bypassing the app lock, unsafe handling of links or backup files, and exported broadcast actions that can be abused by other apps.
